# OFFER — текущее предложение проекта

## Утверждено в проекте
- Действующий сайт работает на WordPress; его тема находится в `wordpress-theme/vetritual-modern/`.
- Приоритет: точные цены, понятные условия услуг, доступные контакты и корректные SEO-страницы.
- Публичные данные редактируются в WordPress без прямого изменения шаблонов.

## Ядро оффера (рабочая версия)
- Сайт посвящён ритуальным услугам для домашних животных:
  - `usyplenie-zhivotnyh`
  - `krematsyja-zhyvotnyh`
  - `vyvoz-zhivotnyh`
- Базовое promise: корректное отображение страницы услуги, понятная форма/контакт и сохранённые SEO-сигналы.

## Что не определено
- Действующие цены находятся в записях `vr_price_group` WordPress.
- Явные коммерческие ограничения (гео, время, каналы связи) — `не определено`.
- Сегментированная линейка доп.услуг — `не определено`.

## Правило правок
- Любые изменения оффера фиксируются в:
  - `DECISIONS.md`
  - `WORKLOG.md`
  - `EVIDENCE.md`
