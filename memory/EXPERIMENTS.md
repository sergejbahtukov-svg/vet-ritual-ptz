# Experiments

Шаблон для фиксации экспериментов/изменений с измерениями.

## Шаблон записи

- Дата: `YYYY-MM-DD`
- Гипотеза:
- Изменение:
- Целевая страница/модуль:
- Ожидаемый результат:
- Риск/контроль:
- Нужные метрики:
- Базовая линия:
- Источник данных:
- Итог:
- Решение (`continue / stop / iterate`):

## Текущий пул

- `не определено` — методика памяти внедрена, активных экспериментов пока нет.

## Политика экспериментов для этого LLM‑wiki
- Любой эксперимент/изменение, влияющее на приоритеты или поведение, фиксируется в этой форме:
  - `гипотеза`, `аудитория`, `изменение`, `основные + контрольные метрики`, `результат`, `решение`.
- Без источника данных и базовой линии (`источник данных`, `базовая линия`) запись считается незавершенной.
- Для каждого завершённого эксперимента обязателен итоговый `DECISION` в `DECISIONS.md`.
