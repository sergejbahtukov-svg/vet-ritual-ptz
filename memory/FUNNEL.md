# FUNNEL — рабочая воронка проекта

## Целевая пользовательская последовательность
1. **Discovery**
   - Вход через SEO/прямой вход на публичные страницы услуг.
2. **Consideration**
   - Чтение описания услуги и контактных инструкций на странице.
3. **Conversion**
   - Обращение/заявка через доступные формы или каналы на сайте.
4. **Delivery**
   - Передача заявки в согласованный процесс интеграции/обработки.
5. **Follow-up**
   - Возврат пользователя через информирование и последующие контакты.

## Подтвержденные точки
- Утвержденные страницы в проекте (`memory/WORDPRESS_MIGRATION_WORKFLOW`): услуга `usyplenie-zhivotnyh`, `krematsyja-zhyvotnyh`, `vyvoz-zhivotnyh`, служебные страницы.
- Наличие `404` и smoke-check перечислений подтверждает контрольную сетку доставки контента.
