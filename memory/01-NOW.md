# 01-NOW — текущий план запуска

## Главная задача
- Подготовить и зафиксировать готовый workflow для миграции Webasyst → WordPress с разбивкой на сабагентов.

## На чем остановились
- Подготовлены и очищены входные документы для нового этапа.
- Следующий шаг: запуск подзадач по роли сабагентов и наполнение их артефактами.

## Режим выполнения на ближайший слот
1. Аудит Webasyst: финализировать карту страниц, блоков и роутов в `memory/WORDPRESS_MIGRATION_WORKFLOW.md`.
2. Архитектура WP: утвердить структуру темы, CPT/ACF/меню/редиректы.
3. Карта контента: связать все URL и смысловой контент с шаблонами.
4. SEO + QA: зафиксировать требования к мета-тегам, OG, schema, redirects и smoke-check.
5. Запусковый маршрут: staging → pilot → production с планом rollback.

## Риски и ограничения
- На этапе перехода нельзя опираться на `preview.html` как источник истины.
- Не открывать тему архивами вне `deploy-vetritual-modern/`.
- Любые изменения в интеграциях делать как кодовую миграцию:
  - загрузка аналитики по согласиям,
  - cookie banner,
  - SEO-блоки в head.

## Контроль результата
- На каждой фазе обязательная запись в:
  - `memory/WORKLOG.md`
  - `memory/DECISIONS.md`
  - `memory/EVIDENCE.md`
