# Vet Ritual — WordPress

## Рабочий сайт

- Публичный сайт: https://vet-ritual-ptz.ru/.
- Локальная проверка: http://localhost/vetritual-wp/.
- Исходники темы: `wordpress-theme/vetritual-modern/`.
- Локальная установленная тема: `C:\xampp\htdocs\vetritual-wp\wp-content\themes\vetritual-modern`.

## Источники данных

- Страницы и тексты: WordPress Pages.
- Меню: зарегистрированные WordPress Menus.
- Услуги, цены, этапы и отзывы: штатные записи `vr_*` и их поля.
- Изображения: Media Library и featured images.
- Глобальные контакты, реквизиты и интеграции: настройки темы.
