# Editable content map

Move any remaining editor-facing template text to the owner below.

- Section labels, section headings and explanatory notes: a Page or a dedicated content record for that section.
- Hero facts and urgency claims: the front Page content or a structured front-page record, never a global JSON option.
- CTA labels and URLs: global defaults may use theme options; page-specific CTAs belong to the Page.
- Footer legal copy: a global theme option.
- Navigation and service links: WordPress menus; do not leave fallback hardcoded links once the required menu exists.
- Button labels such as "Подробнее": a translatable UI string only when it is truly universal; otherwise use the relevant content record.
